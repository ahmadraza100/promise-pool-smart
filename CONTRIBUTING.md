# Contributing to promise-pool-smart

Thank you for your interest in contributing! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/ahmadraza100/promise-pool-smart.git`
3. Create a new branch: `git checkout -b feature/your-feature`
4. Install dependencies: `npm install`

## Development

```bash
# Run tests
npm test

# Run tests in watch mode
npm test:watch

# Type check
npm run lint

# Build
npm run build

# Run examples
node examples.cjs
```

## Code Style

- We use **TypeScript strict mode**
- Code is formatted with Prettier
- Follow ESLint rules
- Add JSDoc comments to public APIs

## Submitting Changes

1. Make your changes in your feature branch
2. Run tests: `npm test`
3. Run lint: `npm run lint`
4. Commit with clear messages: `git commit -am 'Add feature description'`
5. Push to your fork: `git push origin feature/your-feature`
6. Open a Pull Request

## Pull Request Guidelines

- Keep changes focused and atomic
- Include tests for new functionality
- Update documentation as needed
- Reference any related issues

## Reporting Issues

- Use the GitHub issue tracker
- Include steps to reproduce
- Provide example code if applicable
- Include error messages and stack traces
